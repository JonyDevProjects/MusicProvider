# Solución B: Fix YtdlpNativeService para Android

## Objetivo
Hacer funcionar `YtdlpNativeService` en Android compilando el Rust FRB library para Android targets y añadiendo el descargador de binarios de yt-dlp para Android.

## ¿Por qué funciona?

### Problema actual
```
RustLib init skipped: Invalid argument(s): Failed to load dynamic library 'libytdlp_native.so': dlopen failed: library "libytdlp_native.so" not found
```

El Rust FRB native library (`libytdlp_native.so`) no existe en el APK de Android porque:

1. **`ytdlp_setup.rs`** carece de `#[cfg(target_os = "android")]` cases para `release_filename()` y `binary_name()` — el código Rust no compila para targets Android
2. **`GeneratedPluginRegistrant.java`** no registra `RustLibYtdlpNativePlugin` para Android
3. No existe `.symlinks/plugins/rust_lib_ytdlp_native/android/` ni `CMakeLists.txt` para Android

### Solución
1. Añadir `#[cfg(target_os = "android")]` cases en `ytdlp_setup.rs`
2. Compilar el Rust library para `aarch64-linux-android`
3. Registrar el plugin FRB en Android

## Cambios de código requeridos

### 1. rust/ytdlp_native/src/ytdlp_setup.rs

Añadir caso para Android en `release_filename()`:

```rust
#[cfg(target_os = "android")]
{
    "yt-dlp_android.zip"
}
```

Y en `binary_name()`:

```rust
#[cfg(target_os = "android")]
{
    "yt-dlp_android"
}
```

> **Nota**: yt-dlp publica binarios para Linux ARM64. En Android, un binario Linux ARM64 puede funcionar (Android es Linux), pero necesita ser extraído desde el APK o descargado. La URL de GitHub releases `yt-dlp_linux.zip` incluye un binario universal.

### 2. rust/ytdlp_native/.cargo/config.toml

Añadir target para Android:

```toml
# Existing targets for iOS:
[target.aarch64-apple-ios]
rustflags = ["-C", "link-arg=-mios-version-min=15.0"]

[target.x86_64-apple-ios]
rustflags = ["-C", "link-arg=-mios-simulator-version-min=15.0"]

# NEW: Android targets
[target.aarch64-linux-android]
rustflags = ["-C", "link-arg=-lm"]

[target.x86_64-linux-android]
rustflags = ["-C", "link-arg=-lm"]
```

### 3. Android FRB Plugin Registration

Necesario para que `RustLib.init()` encuentre `libytdlp_native.so`:

**a. Crear `rust/ytdlp_native/android/CMakeLists.txt`**:

```cmake
cmake_minimum_required(VERSION 3.22.4)
project("ytdlp_native")

# The FRB-generated CMake that compiles the Rust library
# This is typically auto-generated by `flutter_rust_bridge` codegen
add_library(ytdlp_native SHARED IMPORTED)
set_target_properties(ytdlp_native PROPERTIES IMPORTED_LOCATION
    ${CMAKE_SOURCE_DIR}/../../rust/ytdlp_native/.cargo/target/aarch64-linux-android/release/libytdlp_native.so)
```

> **Nota**: Normalmente FRB v2 genera este CMakeLists.txt automáticamente durante `flutter_rust_bridge:codegen` o un build script. Verificar si `build.rs` o el Flutter plugin registration lo genera.

**b. Añadir a `GeneratedPluginRegistrant.java`** (si no se genera automáticamente):

```java
try {
    flutterEngine.getPlugins().add(new com.example.rust_lib_ytdlp_native.RustLibYtdlpNativePlugin());
} catch (Exception e) {
    Log.e(TAG, "Error registering plugin rust_lib_ytdlp_native", e);
}
```

> **Verificado**: `GeneratedPluginRegistrant.java` actualmente NO incluye `rust_lib_ytdlp_native`. FRB v2 debería auto-registrarlo si el plugin está configurado en `pubspec.yaml` y el `.android/` está presente.

### 4. main.dart (ya hecho en Fase 0)

```dart
try {
  await RustLib.init();
  debugPrint('RustLib initialized successfully');
} catch (e) {
  debugPrint('RustLib init skipped: $e');
}
```

## Riesgos

| Riesgo | Impacto | Mitinación |
|--------|---------|------------|
| yt-dlp binario para Android | Alto | yt-dlp no publica binarios Android oficiales — usar Linux ARM64 |
| Rust cross-compilation toolchain | Medio | Necesita `cargo apk` o Android NDK |
| FRB Android plugin auto-registration | Medio | Verificar con `flutter pub deps` |
| Android security (exec de binarios) | Alto | Android permite exec(), pero scoped storage puede limitar paths |
